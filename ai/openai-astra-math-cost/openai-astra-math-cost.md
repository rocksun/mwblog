OpenAI通过Astra模型成功验证10项数理难题，并首次公开推理成本约为2000美元。这一估算为科研机构提供了基于推理预算规划研究的新思路，标志着前沿AI能力正逐渐从昂贵的训练成本转向可控的API服务化支出。

> 译自：[OpenAI's Astra just proved 10 long-standing math and science theorems. The tokens cost $2,000.](https://thenewstack.io/openai-astra-math-cost/)
> 
> 作者：Amanda Caswell

**OpenAI本周分享了一项重要的研究进展**，宣布其下一代前沿模型Astra的内部版本成功对数学和理论计算机科学领域的10个长期难题进行了机器验证证明——所有这一切仅消耗了价值约2000美元的 [GPT-5.6](https://thenewstack.io/openai-gpt-56-live/) Sol API Token。

这一定价可能是周一公告中最具意义的方面，因为它表明该公司正在引导用户思考：一旦模型问世，一项新发现的成本究竟是多少。

> OpenAI 首次让我们大致了解了这种规模的 AI 推理可能需要多少成本。

需要注意的是，这项工作尚未完成，因为结果仍需人类数学家的进一步审查。然而，对于开发者来说，最大的收获在于 OpenAI 表示该研究过程产生了 10 个新成果，并首次让我们大致了解了这种规模的 AI 推理可能需要多少成本。

OpenAI 尚未发布该内部模型，也未宣布其使用成本。这 2000 美元的估算基于 [GPT-5.6 Sol](https://thenewstack.io/gpt-5-6-developer-reactions/) 的 API 费率。

这种粗略的比较并未计入模型训练、运行周边研究流程或由专家选择问题并评估答案的成本。尽管存在这些局限性，但这种比较对开发者而言仍然很有参考价值。

> 研究实验室很难围绕“模型擅长数学”这样的论断进行规划，但他们可以围绕推理预算进行规划。

## 推理成本优于训练成本

研究实验室很难围绕“模型擅长数学”这样的论断进行规划，但他们可以围绕 [推理预算](https://thenewstack.io/agentic-ai-token-costs/) 进行规划。如果能够通过 API 使用具备前沿推理能力的模型，团队就可以决定准备投入多少资金来研究一个猜想、测试一个可能的证明，或寻找更好的边界。

对开发这些系统的公司而言，最大的成本差异通常来自电力需求，以及 [构建下一代模型所需的数十亿美元资金](https://thenewstack.io/future-proof-ai-infrastructure/)。

然而，对于最终可能通过 API 获取成品模型的研究实验室来说，这些成本并非最重要的。对于这类实验室，相关问题在于：对一个难题进行一次严谨尝试的运行成本是多少。

这正是 OpenAI 估算所传达的基调。初创公司无需拥有自己的前沿模型或堆满 GPU 的仓库，因为它们可以购买已训练模型的推理能力，就像现在的公司租用计算能力而非自建数据中心一样。

## 没有保证，只有机会

当然，投入更多的资金并不能保证取得突破。模型可能会消耗数千美元的 Token，最终却一无所获。

但这种不确定性本来就是研究的一部分，使用 API 也不会改变这一点。不过，它确实为研究人员提供了追求答案的另一种有效途径。

## 研究的推理预算

OpenAI 研究员 Noam Brown 表示，该模型使用的测试时间计算量相对适中，且仍有更大的推理预算空间可用。

该模型并没有解决任何“千禧年大奖难题”，但 OpenAI 似乎认为它尚未达到更大推理量所能产生的结果极限。

尽管如此，开发者和研究团队可能很快就需要决定一个难题到底值多少钱。大学可能会花费数千美元来探索一个数学问题，而如果模型有助于缩小新药的研究范围，制药公司可能会有理由投入更多资金。

OpenAI 展示的是，前沿推理可以像任何其他计算工作负载一样被讨论。

> 尽管如此，开发者和研究团队可能很快就需要决定一个难题到底值多少钱。

## 普及前沿 AI 的获取途径

开发者已经在估算模型生成代码、分析数据库或处理文档集合所需的成本，研究实验室最终也可能进行类似的计算，这将改变哪些人能够尝试前沿系统。构建这些系统可能仍是少数财力雄厚公司的领域，但使用它们可能成为小型研究团队可负担的 [API 支出](https://thenewstack.io/cloudflare-ai-web-economics/)。
