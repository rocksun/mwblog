周五，[Anthropic 发布了 Opus 5](https://thenewstack.io/anthropics-opus-5-almost-fable-5/)，这是其重量级模型的最新迭代版本。Opus 5 在 Opus 4.8 发布仅两个月后问世，紧随 6 月发布的 Mythos 5、[Fable 5](https://thenewstack.io/fable-5-permanent-subscription-access/) 和 Sonnet 5 之后，补齐了新一代产品线——目前仅剩轻量级的 Haiku 等待升级。

尽管规模比旗舰级的 Fable 5 更小，但 Opus 5 的价格显著更低，且限制也少得多。Opus 5 旨在无需持续的人工输入，即可长时间处理编程任务。

## 高性价比的基准测试

Opus 5 的定价为每百万输入 Token 5 美元，每百万输出 Token 25 美元，彻底颠覆了智能代理任务的性价比。在 Frontier-Bench 和 GDPval-AA 等编程和知识工作评估中，Opus 5 确立了新的行业领先水平。

在 OSWorld 2.0 计算机使用基准测试中，它的表现超过了任何价格水平下的其他模型，以不到三分之一的价格超越了 Fable 5 的最佳结果。在需要模型解决全新问题的 ARC-AGI 3 评估中，它的得分是次优模型的 3 倍。

Anthropic 在[公司公告](https://www.anthropic.com/news/claude-opus-5)中写道，Opus 5 在“验证自身工作并仔细迭代直至成功方面表现得强大得多”。在基准测试期间，给模型一个不完整的提示，并刻意阻止其查看机器部件的图纸。它没有放弃，而是编写了自己的计算机视觉流程，从图像数据中重构出了该部件。

由于 Opus 5 的运行成本更低，团队有能力让它处理更大规模的编程任务。这也意味着需要以不同的方式思考安全性，这也是微型虚拟机（microVMs）受到更多关注的原因之一。与长期运行的容器不同，它们为平台团队提供了一个隔离环境，一旦任务完成，他们就可以立即将其销毁。

## 为无监督智能代理提供的安全性

当一个模型在没有持续人工监督的情况下跨多个系统工作时，访问权限必须是临时的且易于撤销。这就是为什么越来越多的注意力转向短期、即时（just-in-time）的凭证，类似于 [1Password 正在为 Claude 开发的委托认证模型](https://thenewstack.io/1password-agent-authentication-framework/)。

给人工智能赋予无情的持久性有一个隐患：它不知道何时该停止。标准的 API 日志无法及时标记这种行为。团队必须构建更智能的遥测系统，真正理解工作流的上下文。你需要一个语义电路断路器，在模型耗尽你的计算预算之前切断电源。

## 控制失控的 Token 开销

与 Fable 5 相比，Opus 5 降低了每个 Token 的价格标签，但[自动编程仍然可能很快变得昂贵](https://thenewstack.io/agentic-ai-token-costs/)。一个在后台循环工作数小时的智能代理在提交 PR 之前会消耗数百万个 Token。对于平台团队来说，按会话管理支出成为了新的运营要求。

为了防止这些后台作业在边缘案例中崩溃，Anthropic 正在发布测试版的自动回退（Automatic Fallbacks）功能。如果提示词在 Opus 5 上触发了安全分类器，API 会悄悄将任务重定向到 Opus 4.8，而不是抛出硬错误并中断整个流水线。

Opus 5 还继承了其前身的零保留策略，绕过了 Fable 和 Mythos 强制要求的 30 天数据记录。

要了解 Anthropic 期望这些环境约束在何处运作，看看他们是如何人为限制该模型的会有所帮助。该公司正在短视域能力和长视域安全之间寻求精妙的平衡。

## 生物学能力与谨慎限制

Anthropic 发言人告诉 *The New Stack*，Opus 5 是“在生物学任务上对比 Opus 4.8 的重大改进，使其成为我们可用于科学研究的最强大通用模型”。在内部有机化学基准测试（如从光谱数据推断分子结构）中，它的得分比 Opus 4.8 高出 10.2 个百分点，在预测蛋白质序列变异如何决定功能方面高出 7.7 个百分点。

然而，Anthropic 的测试揭示了“在长期运行的自动研究任务上存在显著局限性”，他们认为这些任务具有最高的潜在风险。因此，Opus 5 保留了与 Opus 4.8 相似的生物学安全措施组合。虽然在 Fable 5 上被阻止的生物学相关请求现在将路由到 Opus 5 而不是 4.8，但不受限制的 Mythos 5 对于自动药物设计等长期、开放式工作而言仍然是更强大的模型。

Opus 5 可以审查源代码以进行防御性安全工作。Anthropic 表示，这些[安全措施的激活频率应该远低于 Fable 5](https://thenewstack.io/fable-5-honeycomb-opus/)——据该公司称，大约减少了 85%。

显然，模型正在快速改进，但现在更大的挑战是确保它们运行的平台能够跟上步伐。
