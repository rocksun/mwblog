**Cursor 是最新一家瞄准印度市场**并推行本地化定价的 AI 公司，周二宣布推出一项远低于其现有 Pro 订阅计划的专属方案。

在此之前不久，有消息称 Anthropic 正在为印度的 Claude 用户推出卢比定价。然而，折算成美元后，Anthropic 的印度定价实际上比美国本土版本还要贵。

这些动作相隔仅两周，反映出大型 AI 公司正日益重视在全球最大、增长最快的开发者市场之一占据有利位置。Cursor 在宣布该推出的博客文章中提到，其印度用户群在过去一年中增长了两倍，达到 300 多万开发者，使其成为该公司的第三大市场。

“这里也是全球范围内拥有最多‘超级用户’的市场，印度开发者的单位开发者 AI 代理请求数超过了世界上任何其他地区，”该公司补充道。

> “这里也是全球范围内拥有最多‘超级用户’的市场，印度开发者的单位开发者 AI 代理请求数超过了世界上任何其他地区。”

Anthropic 的情况类似，此前曾披露就 Claude.ai 的使用量而言，印度是其仅次于美国的第二大市场。

## 范例

这项名为 Cursor Start 的新计划每月收费 ₹649（约 7 美元），远低于 Cursor 标准的每月 20 美元 Pro 计划，并以卢比结算。该计划捆绑了 [Cursor 自有的 Composer 模型](https://thenewstack.io/cursor-composer-benchmarks/) 和 [SpaceXAI 的 Grok 4.5](https://thenewstack.io/grok-45-opus-killer-launch/)，以及云代理、Cursor iOS 应用和 MCP 支持——但不包含来自 OpenAI 或 Anthropic 的前沿模型，也不含 Bugbot、自动模式、自动化功能或 Cursor SDK 等 Pro 专属特性。

这突显了 Cursor 一直投资自有模型的关键原因之一。Composer 让 Cursor 无需依赖昂贵的第三方前沿模型，也不受制于其价格或可用性波动，且相比大规模授权 OpenAI 或 Anthropic 的模型，其运行成本更低——这正是让 Cursor Start 这种低价计划在商业上可行之处。

深入挖掘 Cursor 新计划的细节揭示了一个重要点：它支持 [UPI](https://en.wikipedia.org/wiki/Unified_Payments_Interface)，即统一支付接口。该接口支撑了印度绝大多数的数字交易，让用户可以直接通过银行账户付款，而无需依赖信用卡或应用商店结算。这可能被证明是 Cursor 本地化工作的一个至关重要的组成部分。

这也凸显了 Cursor 的方法与 Anthropic 为同一市场进行本地化努力之间的关键差异。

“长期以来，我们在印度的用户一直向我们提出两点要求：能够反映本地市场的定价，以及使用 UPI 支付的能力，”该公司写道。

> “长期以来，我们在印度的用户一直向我们提出两点要求：能够反映本地市场的定价，以及使用 UPI 支付的能力。”

## Claude 的行动

在定价方面，Anthropic 目前的主要举措是将定价转换为卢比，而不是美元。根据 [TechCrunch 7 月 13 日的报道](https://techcrunch.com/2026/07/13/anthropic-starts-localizing-claude-pricing-for-india-its-biggest-market-after-the-us/)，Claude Pro 每月售价为 ₹2,000（按年计费时约 21 美元），Claude Max 起售价为 ₹11,999（约 125 美元），Team 计划每席位起价 ₹2,399——所有价格以美元计算都高于其美国本土版本。最关键的是，Anthropic 尚未增加对 UPI 的支持，用户仍需通过银行卡或苹果和谷歌的应用商店进行支付。

对此有一个轻微的提醒：Anthropic 尚未正式宣布这一变更，且推广似乎正在逐步触达用户，因此定价——甚至包括 UPI 支持的缺失——在正式发布前仍可能发生变化。

值得注意的是，OpenAI 实际上率先进入了印度。该公司于 2025 年 8 月在那里[推出了 ChatGPT Go](https://techcrunch.com/2025/08/18/openai-launches-a-sub-5-chatgpt-plan-in-india/)，价格仅为其全球价格的一小部分，且从第一天起就支持 UPI，随后又将该计划[扩展到其他 170 多个国家](https://openai.com/index/introducing-chatgpt-go/)。

在印度，Go 目前每月费用为 ₹399（约 4.15 美元）——舒适地低于 Cursor Start，仅为 Anthropic 或 OpenAI 自身 Plus 和 Pro 计划成本的一小部分。

在这三个举措之间，出现了一个明确的分歧：Cursor 和 OpenAI 都将印度视为一个需要独立计划、独立价格和独立支付方式的市场。而据目前的报道，Anthropic 大多只是做了货币转换。

> “Cursor 和 OpenAI 都将印度视为一个需要独立计划、独立价格和独立支付方式的市场。”

然而，单靠价格并不能决定谁提供了更好的交易。OpenAI 的 Go 计划是三者中最便宜的，但它是为一般对话构建的——更长的对话、更多的消息、图像生成——而不是为编写代码的人准备的。Cursor Start 的价格稍高，但它的目标是特定类型的用户：希望拥有 IDE、代理和编码专用模型，而不必为那些永远不会碰到的花哨功能买单的构建者。

对于该受众群体而言，₹649 可能比 ₹399 购买到了更具相关性的价值，这种区别真正证明了 Cursor 在掌握更多技术栈方面所做努力的合理性。
