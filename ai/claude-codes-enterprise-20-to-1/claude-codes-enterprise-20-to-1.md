根据Anthropic的IPO招股书显示，Claude Code成为其企业增长的核心驱动力。顶级企业用户的消费是普通Claude用户的20倍，且公司九成代码由Claude编写，展现了惊人的AI开发效率与商业潜力。

> 译自：[Claude Code's top enterprise users outspend other Claude users 20 to 1, Anthropic's IPO filing says](https://thenewstack.io/claude-codes-enterprise-20-to-1/)
> 
> 作者：Matthew Burns

**Anthropic的IPO招股书将 Claude Code 置于其企业增长故事的核心。** 该公司周一向纳斯达克提交了上市申请。其 S-1 文件显示，在第三季度，没有使用 Claude Code 的普通 Claude 企业用户每月花费不到 75 美元。而在 Enterprise 上使用 Claude Code 的前 5% 的用户花费大约是这个数字的 20 倍。

Anthropic 的 S-1 招股说明书阐述了一种经典的“攻城拔寨并扩大份额”（land-and-expand）策略，其中 Claude Code 负责攻城拔寨。一名工程师开始使用 Claude Code，觉得很好用，便开始在内部进行推广。Anthropic 的销售团队随后跟进，招股书称，到那时，“Claude 通常已经在使用中了。”

> Anthropic 称 Claude Code 是“我们认为最具体地定义了自主 AI 工作样貌的产品”

Anthropic 称 Claude Code 是“我们认为最具体地定义了自主 AI 工作样貌的产品”，并表示非技术团队也正在采用它。对于一个从终端起步的工具来说，这太疯狂了。

收入数据与这一说法相吻合：Anthropic 表示，截至 2026 年 9 月 30 日的过去 12 个月中，其拥有超过 11,900 名付费达到或超过 100,000 美元的客户，高于一年前的 950 多名。2026 年上半年营收达到 163 亿美元，高于 2025 年同期的 12 亿美元。其中 Token 使用量占了 50%。

Anthropic 自己的工程师呢？根据招股书，在 9 月份，Claude 编写了该公司代码库中超过 90% 的代码贡献。

> Anthropic 还表示，在第三季度，平均每位工程师每天产出的代码量是 2024 年的 45 倍以上。Anthropic

Anthropic 还表示，在第三季度，平均每位工程师每天产出的代码量是 2024 年的 45 倍以上。Anthropic 表示，其工程师越来越多地指导和审查 Claude 的工作，尽管它没有定义什么是“代码贡献”，也没有说明这些代码得到了多少人工审查。

我一直在用 Claude Code 每周构建一个项目，而我几乎不知道自己在做什么。潜在的速度提升是非常真实的。

S-1 还解释了为什么 Anthropic 除了编码之外还关心 Claude Code。该公司向其他开发者销售运行 Claude Code 的软件。

S-1 写道：“单纯的模型不是智能体。”开发者可以通过智能体 SDK 在自己的服务器上运行 Anthropic 的控制框架，或者付费让 Anthropic 作为 Claude 托管智能体来运行它。

这使得 Anthropic 更接近那些在其模型之上构建编程智能体的公司。TNS 曾报道过 [GitHub 和 Anthropic 如何在重大的 Rust 重写中使用他们自己的智能体](https://thenewstack.io/github-copilot-anthropic-rust-migration/)，并采用了截然不同的策略，以及 [AWS 如何开源了一个声称比 Claude Code 和 Codex 便宜 45% 的智能体](https://thenewstack.io/aws-strands-harness-agent/)。

> S-1 将 Google 和 OpenAI 列为 Anthropic 在前沿模型领域的主要竞争对手。

S-1 将 Google 和 OpenAI 列为 Anthropic 在前沿模型领域的主要竞争对手。Cursor、Replit 和 Cognition 并未出现在其中。

在其风险因素中，Anthropic 将 Claude Code 列为其自身开发工作中的关键工具之一，因此该产品的问题“可能会直接损害我们开发和部署未来模型的能力”。

它还警告说，随着 Claude 承担更多工程和研究工作，“我们可能会失去对某些过程的可见性，这种方式可能会变得难以让任何个人或人类群体去理解和控制。”

这与 Anthropic 公开呼吁放缓前沿发展步伐的立场相呼应，[Dario Amodei 曾表示，这种立场可能让该公司失去了 AI 领先地位](https://thenewstack.io/anthropic-mythos-safety-pace/)。

Anthropic 计划在纳斯达克上市，股票代码为 ANT。招股书未包含价格区间。
