**Anthropic $200 方案的 Claude Code 用户将不再面临滚动五小时的使用上限**，前提是他们的账户经过验证且仍有每周使用额度。

Anthropic 在周五[宣布了这一变化](https://x.com/claudeai/status/2116220869479428500)，同时将其两个顶级消费计划重新命名。Max 5x 现在更名为 Max，Max 20x 则变为 Ultra。它们的费用仍然分别为每月 $100 和 $200，现有订阅者无需采取任何操作即可进行切换。

> Max 5x 现在更名为 Max，Max 20x 则变为 Ultra。

Anthropic 的[定价页面](https://claude.com/pricing)还列出了每月的 Claude 平台 API 额度：Max 方案为 $100，Ultra 方案为 $200。这为在使用 API 构建应用程序的同时使用 Claude Code 的开发者增加了另一个考量因素，每个计划都捆绑了与其每月订阅价格相等的 API 额度。Claude Code 的创建者 Boris Cherny [在自己的帖子中强调了这一限制的变化](https://x.com/bcherny/status/2116222842413142111)。

## 五小时上限意味着什么

五小时限制对滚动时间窗口内的使用量进行了封顶，一项繁重的任务可能会更快地耗尽该额度。Claude Code 用户可能会在调试或进行大型重构的中途触及上限，尽管他们的每周使用额度仍有剩余，却不得不等待重置。

## 验证优先

一些 Ultra 订阅者必须等待 Anthropic 验证其账户后，五小时限制才会取消。该公司表示，这些检查有助于防止欺诈和滥用，并会在解除上限时向用户发送电子邮件。

> 一些 Ultra 订阅者必须等待 Anthropic 验证其账户后，五小时限制才会取消。

根据 [Anthropic 的说法](https://support.claude.com/en/articles/17728952-what-is-the-ultra-plan)，验证是根据账户和付款历史记录自动进行的。目前无法请求或加速该过程，因此某些用户只能保持耐心。

## 每周上限依然存在

Ultra 用户仍然拥有相同的每周额度，如果没有五小时限制迫使他们暂停，他们可能会更快地用完这些额度。定价页面显示，Ultra 的每周使用量是 Pro 的 10 倍，而 Max 的每周使用量是 Pro 的 5 倍。

> 定价页面显示，Ultra 的每周使用量是 Pro 的 10 倍，而 Max 的每周使用量是 Pro 的 5 倍。

无论您是在网页端、桌面端还是移动端，您与 Claude 的聊天都计入与 Claude Code 会话相同的每周限制中。一旦用完了该额度，您可以开启使用额度以标准 API 速率继续工作，不过您需要在订阅费之外支付额外费用。

如果您在每周额度有剩余的情况下仍然不断触及会话限制，那么与 Max 相比，Ultra 每月多花 $100 来避免这些中断可能是值得的；但如果您在一周结束前就已经用完了额度，取消会话上限并不会为您提供更多包含的使用量。

## OpenAI 放宽限制

前一天，OpenAI 的 Thibault Sottiaux [宣布为 Pro 订阅者和商业高级版提高使用限制](https://x.com/thsottiaux/status/2115850175868727621)。

在客户反对之后，OpenAI 还放弃了对现有 $200 Pro 订阅者的计划降价。在另一项定价决策中，在开发者的强烈反对后，该公司[放弃了用固定的每项任务费用取代基于 Token 的计费的想法](https://thenewstack.io/openai-token-pricing-reversal/)。
