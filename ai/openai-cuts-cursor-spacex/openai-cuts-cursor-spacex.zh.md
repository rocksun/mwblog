**OpenAI 于周五表示**，已通知 SpaceX，计划终止其向 Cursor（Elon Musk 旗下的 AI 代码编辑器）提供 OpenAI 模型的合同。

“我们做出这一选择是因为，基于我们此前与 [Elon Musk](https://thenewstack.io/x-open-source-codebase/) 旗下公司违反合同的经验，我们无法确信 SpaceX 会在我们的服务条款内使用我们的技术，”OpenAI [声明](https://openai.com/index/our-decision-on-cursor-following-its-acquisition-by-spacex/)称。

合同拟定的截止日期为 2026 年 11 月 12 日。那些投入时间与精力通过 [Cursor](https://cursor.com/home) 学习 [OpenAI](https://thenewstack.io/openai-launches-gpt-5-5-calling-it-a-new-class-of-intelligence/) 技术的开发者，如今因超出其控制范围的企业博弈而可能陷入困境。

“我们深知这一决定对那些依赖 Cursor 中 OpenAI 模型的开发者影响最大。我们关心他们在过渡期间的体验，并准备好全力以赴支持他们，”该博客文章以一种和解的语调写道。

> “基于我们与 Elon Musk 旗下公司违反合同的经验，我们无法确信 SpaceX 会在我们的服务条款内使用我们的技术。”

## OpenAI 表示其“深切关心”开发者。

OpenAI 的举措似乎针对的是 SpaceX 更广泛的企业使命及其行为特征，而非该组织内部那些在 Cursor 上工作的、无疑非常优秀的软件开发人员。因此，OpenAI 通过提供合同要求的“最大通知期限”，最大限度地延长了开发者通过 Cursor 使用其模型的时间。

“这个决定非常艰难，因为我们非常关心我们的模型能够广泛地提供给开发者，”OpenAI 表示。

SpaceX 于 6 月同意[收购](https://thenewstack.io/spacex-cursor-ai-coding/) Cursor 的制造商 Anysphere，并于 8 月 14 日完成了收购。OpenAI 表示，它与 Cursor 团队合作了“近四年”，这几乎涵盖了该产品存在的全部时间。

该组织解释了在与 SpaceX 等大型企业合作时，如何利用定制合同来确保其服务条款的合规性。这种定制化衔接旨在确保当平台发生集成时，能够充分保障大规模使用下的安全性。

## Elon Musk “打破并违反”了合同和服务条款

援引《纽约时报》的一篇报道，OpenAI [指出](https://openai.com/index/our-decision-on-cursor-following-its-acquisition-by-spacex/#:~:text=After%20Musk%20acquired,to%20xAI%E2%80%99s%20own)。)：“在 Musk 收购 Twitter（现为 SpaceX 的一部分）后，该公司违反了我们的合同条款（以及许多其他条款）。今年早些时候，Musk 在宣誓下承认，现同为 SpaceX 一部分的 xAI 违反了 OpenAI 的服务条款（这些条款与 xAI 自己的条款类似）。”

OpenAI 详细阐述了其不满，进一步提到 [Musk 承认](https://www.forbes.com/sites/antoniopequenoiv/2026/04/30/elon-musk-admits-xai-distilled-openai-data-to-train-models-heres-what-that-means/)，作为 SpaceX 内部的运作组织，“xAI 违反了 OpenAI 的服务条款”。

## 法律与政策分析师的观点

法律与政策分析师、《The Mitchell Report》出版人 [Andrellos Mitchell](https://www.linkedin.com/in/andrellos-mitchell-bsw-ma-jd-083372b2/) 告诉 *The New Stack*，只要 OpenAI 在其合同条款内行事，他不明白为什么人们期望它继续维持一段它不再信任的业务关系。

“我认为 OpenAI 与 Musk 的公司和产品需要彻底且永久地分道扬镳——他们的关系已经变得太具对抗性了。在某种程度上，继续做生意已经没有意义了，”Mitchell 说道。

在为这些举措对程序员的影响感到遗憾时，Mitchell 同意开发者“肯定会感到不便”，有些人可能不得不改变他们的工作方式。但他表示：“开发者都是有才华的人，”即他们会找到新的工具、新的项目和新的工作来投入。

> “这里更大的教训是，没有开发者应该认为任何特定的企业关系是永久的。公司会易主。合同会到期。业务关系会破裂。这是市场的一部分。当这种情况发生时，开发者必须准备好去适应，”Mitchell 强调道。

## 模型蒸馏技术的不正当使用

一项指控涉及 xAI 在训练其模型时部分使用了 OpenAI 的技术，OpenAI 将其描述为被禁止的蒸馏行为。Musk 承认 xAI 在这方面“部分”使用了 OpenAI 的技术。

雪上加霜的是，OpenAI 在声明中提醒公众，其服务条款与 xAI 自身关于运营授权的规定并无不同。

“随着 AI 能力的提升，我们也有了新的责任，以确保我们即将推出的模型 [Astra](https://openai.com/index/responding-next-frontier-critical-cyber-capabilities/) 按照我们的条款使用。鉴于这一切，我们决定将合同终止日期延迟到我们能做到的最晚日期，同时不再向 Cursor 提供未来的模型，”OpenAI 表示。

***另见：** [OpenAI 的 Astra 可以完成研究人员一周的工作量。这正是问题所在。](https://thenewstack.io/openai-astra-persistent-agents/)*

## 更广泛的反应、收缩与影响

Cursor 的联合创始人兼 CEO（现为 SpaceX 员工）[Michael Truell](https://www.linkedin.com/in/michael-t-5b1bbb122/#) 在 X 上写道，很遗憾看到 OpenAI 的封锁意图公之于众。

“OpenAI 模型承载了 Cursor 用户约 5% 的流量，我们正在与 OpenAI 团队沟通以解决此问题。Cursor 是 OpenAI 最早的用户之一；我们与他们的团队密切合作多年，并一直信任他们的平台，将其作为我们业务的中立基础设施，”Truell 写道。

Anthropic 联合创始人兼首席计算官 [Tom Brown](https://www.linkedin.com/in/nottombrown/) 利用了这个机会，强调了其公司与 Cursor 之间持续的联系。他[在 X 上表示](https://x.com/NotTomBrown/status/2093541294027280657)：“自 Sonnet 3.5 发布以来，Cursor 一直是 Anthropic 值得信赖的合作伙伴。我们将继续增加算力以支持 Cursor 中的 Claude 模型，并对他们加入 SpaceX 后的未来感到兴奋。”

[Open Machine](https://openmachine.ai/) 的 AI 初创公司顾问、前 IBM Watson 及 AWS 机器学习负责人 [Allie K. Miller](https://www.linkedin.com/in/alliekmiller/) 在 X 上写道：“我很难想象 OpenAI 会继续向一家由 Musk 领导的公司提供模型访问权限。也许如果 SpaceX 的结构发生变化从而允许这样做，但那将是一个巨大的转变。”

## 开发者接下来可以转向哪些替代方案？

为了在 Cursor 应用程序中继续使用 OpenAI 模型，OpenAI 邀请开发者[选择最适合其工作流程的三种选项之一](https://help.openai.com/en/articles/20001506-using-openai-models-in-cursor)。

* 选项 #1 是自带 OpenAI API 密钥。这意味着开发者可以继续在 Cursor 的本地聊天和 Agent 功能中使用 OpenAI 模型，但将根据 [OpenAI API 价格](https://developers.openai.com/api/docs/pricing)进行计费。
* 选项 #2 是使用 Codex IDE 扩展；这意味着开发者将通过 ChatGPT 订阅或 OpenAI API 密钥，直接在 Cursor 中使用 OpenAI 的 AI 编码助手 Codex。
* 选项 #3 是使用 AI 网关提供商，这意味着开发者将通过其在 Amazon Bedrock、Azure 或其他兼容 OpenAI 的网关等兼容提供商处的账户，将 Cursor 连接到 OpenAI 模型。

这并非 OpenAI 首次因担心模型在蒸馏方面的潜在或涉嫌滥用而采取行动。今年 2 月，[路透社报道称](https://www.reuters.com/world/china/openai-accuses-deepseek-distilling-us-models-gain-advantage-bloomberg-news-2026-02-12/)，OpenAI 已警告美国立法者，“中国 AI 初创公司 DeepSeek 正在瞄准这家 ChatGPT 的制造商”以及国内领先的 AI 公司，旨在复制模型并将其用于自身的训练。
