**当 Anthropic 本月发布 Claude Fable 5.1 时**，它将发布重点聚焦于一项基准测试结果：其 [Terminal-Bench-Science](https://www.tbench.ai/news/terminal-bench-science-0-1) 得分。

在此基准测试中，模型会获得一个终端环境和一个需要独立解决的现实科学研究问题。[Fable 5.1](https://thenewstack.io/anthropic-fable-5-1-launch/) 得分为 52.6%，而 Fable 5 为 24.7%。按照 Anthropic 的评分标准，新模型的性能提升了一倍以上。

Anthropic 公布的得分是在大多数用户无法企及的条件下得出的。该基准测试允许每个模型在每个任务上花费长达八小时的时间，但 Anthropic 并未说明其获取这些数字所使用的工具链或预算。当该基准测试的 [排行榜](https://snorkel.ai/leaderboard/terminal-bench-science/) 对 Fable 5 进行测试时，它通过 Claude Code 全力运行，在 210 次尝试中花费了 14,180 美元，平均每次尝试花费约 67 美元。

大多数人并不会在实验室环境中使用 Fable，因此我想了解普通用户在这些任务中会得到什么结果。我最近 [测试了 Fable 5 和 Fable 5.1 在日常工作中的表现](https://thenewstack.io/claude-fable-upgrade-tested/)，发现它们比基准测试显示的要接近得多。这让我决定以普通家庭用户的方式运行这些基准测试任务，看看模型之间的差异到底在哪里。

该基准测试的 70 个任务是 [公开的](https://github.com/harbor-framework/terminal-bench-science)，所以我从中选取了 5 个任务，每个科学领域各一个，并亲自运行了这两个模型。

## 测试过程

Terminal-Bench-Science 包含五个类别，每个类别下有多个测试。我为每个类别选择了一个可以在 Python 环境中运行的测试。以下是我选择的任务：

* **符号回归（数学）** – 一个包含 100 个变量和隐藏公式的数据集，其背后有一个“是/否”标签。模型必须找到一个适用于从未见过的数据的预测器。
* **Lorenz-96 同化（地球科学）** – 从几个带有未知时钟偏移的非校准传感器中重构一个混沌大气模型。评分基于五个标准，结果非零即一。
* **反应堆安全控制（工程学）** – 为化学反应堆编写控制器，在不超出温度限制的前提下，尽可能快地完成每一批次任务，并涵盖公开和隐藏的故障场景。
* **觅食认知模型（生命科学）** – 逐次预测 20 只老鼠中每一只会按压哪个杠杆，评分基于模型从未见过的会话。
* **纳米压痕（物理科学）** – 从原始压痕曲线中提取材料属性，这些曲线包含漂移、粘附、缺陷和未知的尖端形状。

每次运行都使用一个普通的终端，我为每个测试设置了 12 美元的成本限制和 60 次轮次限制。整套十次运行大约花费了 12 小时。

## 符号回归

这是唯一一个有模型通过了基准测试的隐藏测试的项目。Fable 5.1 工作了 27 个轮次，找到了隐藏结构，编写了预测器，并在 11.8 分钟后自行停止，输出了 27,088 个 token，仅花费 1.96 美元就通过了此项测试。

Fable 5 在 53.5 分钟内用尽了所有 60 个轮次，生成了 39,461 个输出 token，花费 4.20 美元，但最终失败。我运行了第二次 Fable 5 以排除运气因素。它再次用尽了 60 个轮次，耗时 60 分钟，生成 60,608 个输出 token，花费 6.38 美元，依然失败。

## Lorenz-96 同化

这是成本最高的一组运行。Fable 5 在 97.7 分钟和 92,091 个输出 token 后，在第 45 轮达到 12 美元的成本限制，最终花费 12.63 美元。Fable 5.1 在 126 分钟内用尽了全部 60 轮，生成了 89,789 个输出 token，花费 10.70 美元。在公开排行榜上，地球科学也是 Fable 5 得分接近于零的领域，这两个模型在这里都失败了。

## 反应堆安全控制

两个模型都没有编写出能通过评分程序场景的控制器。这次运行产生的输出 token 最多，Fable 5.1 生成了 157,710 个。它在 40.9 分钟后达到 60 轮限制，花费 11.53 美元。Fable 5 在 63.8 分钟后，在第 49 轮达到成本限制，生成 121,978 个输出 token，花费 12.04 美元。

## 觅食认知模型

这是测试系列中耗时最长的一次运行。Fable 5.1 是唯一宣布完成的模型。它构建了一个模型，根据自己的评分循环对其进行测试，并在 43 个轮次后、53.5 分钟时宣布完成。它生成了 65,518 个输出 token，花费 5.65 美元。但官方评分程序拒绝了它。

Fable 5 没有宣布任何结果。它在 139.3 分钟和 62,587 个输出 token 后，在第 60 轮达到 12 美元限制，最终花费 12.13 美元。

## 纳米压痕

两者均失败。它们将大部分时间都花在了读取原始曲线和编写代码进行分割上。均未产生评分程序接受的结果文件。Fable 5.1 在 29.6 分钟、115,687 个输出 token 后用尽了轮次，花费 10.91 美元。Fable 5 在 34.1 分钟、114,239 个输出 token 后用尽了资金，最终花费 12.59 美元。

## 结果

以下是具体数据结果。

|  |  |  |
| --- | --- | --- |
| **指标** | **Fable 5 分数** | **Fable 5.1 分数** |
| **解决的任务数** | 0 / 5 | 1 / 5 |
| **输出 Token 数** | 430,356 | 455,792 |
| **总成本** | $53.59 | $40.75 |
| **总耗时** | 388 分钟 | 262 分钟 |
| **因成本限制结束的运行数** | 4 | 0 |

该基准测试对所有 70 个任务进行了评分，每个任务尝试三次，Anthropic 的 24.7% 和 52.6% 得分来自于那套完整的测试套件。独立排行榜将 Fable 5 的得分定为 21.4%，接近 Anthropic 的数据。Fable 5.1 尚未进入独立排行榜，因此其 52.6% 的得分仅来自 Anthropic。我的测试结果 0% 和 20% 均低于两者。五个任务只是一个小样本。

即使官方公布的分数完全正确，凭运气得到这些结果也是合理的，所以这次测试既没有证实也没有反驳其性能提升一倍的说法。趋势是吻合的，因为新模型表现更好。Fable 5.1 解决的唯一一项任务是在数学领域，这也是排行榜显示 Fable 5 表现最好的领域。

## 我的看法

我不认为普通用户会感觉到 Fable 5 和 Fable 5.1 之间有太大区别。我只运行了少量测试，所以无法证明或否定 Anthropic 的基准测试结果。但我所看到的表明，这种差距不会传导给普通用户。唯一表现出来的差异是在账单上。Fable 5.1 失败得更快、更便宜，且从未触及我的成本限制，而 Fable 5 触及了四次。

假设你的工作更像基准测试任务；那么工具链和预算与模型本身一样重要。拥有专门构建的工具链、充足的任务时间以及大得多的预算，你可能会更接近 Anthropic 的数字。
