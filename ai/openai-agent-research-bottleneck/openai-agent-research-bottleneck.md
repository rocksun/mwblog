OpenAI数据显示，尽管AI代理能处理大量研究任务，但由于人类需要耗费大量精力进行监督、调试与审核，研究人员的工作压力反而不降反升，且AI带来的工作量增加难以转化为实质性的研究进展。

> 译自：[AI agents are creating more work, not less — and OpenAI's own numbers back it up](https://thenewstack.io/openai-agent-research-bottleneck/)
> 
> 作者：Amanda Caswell

OpenAI 表示已达成去年秋季设定的目标，研究人员目前正在使用该公司所称的“自动化研究实习生”，这是一个能够处理通常需要研究人员几天时间才能完成的明确任务的代理。

[数据表明](https://openai.com/index/research-acceleration-view-inside-openai)编码代理的使用在 2026 年全年持续攀升，到 8 月中旬，其研究组织内每 1 个工作日的人力投入对应着 3.1 个代理工作日。中位数研究人员每天在 API 价格上的推理成本超过 600 美元，而处于前 10% 的研究人员每天花费超过 7,000 美元。

> 中位数研究人员每天在 API 价格上的推理成本超过 600 美元，而处于前 10% 的研究人员每天花费超过 7,000 美元。

## 代理工时与有效产出

但众所周知，代理工作日和人类工作日并不等同。该公司将代理执行任务的时间换算为标准的八小时工作日。由于研究人员可以同时运行多个代理，这一数字告诉我们代理的工作时长，但不一定代表它们完成了什么。

对于工程团队来说，这意味着人类端仍有大量工作，因为运行更多的代理可以增加同时处理的工作量，但也可能增加人类需要跟进的工作量。

OpenAI 对研究实习生的非常具体的定义强调，它必须能够完成通常需要熟练人员几天时间才能完成的明确研究任务，但决策权仍掌握在人类手中。该公司的下一个目标是自动化 AI 研究员，他们希望在 2028 年 3 月之前实现这一目标。

## 监督成为制约因素

利用 Epoch AI 的分类法，OpenAI 将代理的工作分为六个领域——决策、设计、构建、运行、分析和交流——并发现 1 月至 8 月期间所有六个领域的工作量均有所增加，尽管代理在决定追求何种研究方面所做的工作仍然相对较少。

大部分工作是实用的，代理编写研究和基础设施代码、监控实验，并提供足够的技术支持，以至于 OpenAI 表示参加调试办公时间的人数减少了，导致一个团队甚至完全停止了此类会议。

然而，更多的代理工时并不自动意味着更有用的研究。OpenAI 表示，代码输出和实验数量相对容易跟踪，但这两者都无法显示这些代理实际上取得了多少进展。随着实验数量的增加，计算需求也显著增长。

OpenAI 使用了另一个模型来评估代理在不同难度任务上的表现，并发现尽管 1 月至 7 月间的成功率有所提高，但在原本需要人类花费 4 到 8 小时的成功任务中，仍有超过一半需要人类介入。

## 安全事件限制了 Astra 的部署

一旦工程师能够同时运行多个代理，并且这些代理能够自行启动子代理，挑战就转变为如何跟上它们的产出——捕获偏离轨道的运行、审查代码差异，以及决定什么可以发布或输入到训练运行中。

[Astra 的持久化代理功能已经允许研究人员移交多日任务](https://thenewstack.io/openai-astra-persistent-agents/)，这使得这种监督负担变得更糟，而不是更好。

该公司承认，随着代理接管了更多的执行工作，最难自动化的研究部分将消耗工程师更多的时间，从而对一个人能够实际审查的代理产出量设定了实际的上限。

7 月 20 日，由代理引起的一系列中断严重扰乱了 OpenAI 的研究基础设施，以至于该公司将训练容器服务下线，随后在更严格的限制下重新上线。

近一个月后的 8 月 7 日，OpenAI 再次收紧了访问权限，因为早期证据表明 Astra 可能触及了其《准备框架》中的“关键”网络安全阈值，将该模型限制在更高安全性的研究领域，并增加了[开发者可能已经遇到的作为意外 API 中断的防护措施](https://thenewstack.io/astra-api-safety-stops/)。

## 工作负载在模型间快速转移

接下来的那一周，Astra 级别的 GPU 分配下降了 59.2%，但这些计算资源并没有闲置太久。研究人员将大部分工作转移到了其他模型上，这些模型的 GPU 分配增加了 17.2%，弥补了 Astra 使用量下降约 85% 的缺口。这些限制不仅没有减少运行的工作量，反而将其推向了其他模型，这显示了当系统的一部分被锁定后，工作负载是多么容易转移。

OpenAI 的研究人员正在将更大的工作移交给代理，同时运行更多的代理并启动更多的实验，但这种做法是否转化为更快速的研究更难衡量——而 OpenAI [仍在研究如何对其进行定价](https://thenewstack.io/openai-outcome-based-pricing/)。
