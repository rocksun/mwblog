[Nvidia](https://www.nvidia.com/en-us/) 已确认同意以 129 亿美元的巨额交易收购 [Hugging Face](https://huggingface.co/)。这笔交易将把人工智能行业最重要的开放模型平台之一，纳入全球占主导地位的 AI 芯片制造商——也是目前地球上市值最高（市值远超 5 万亿美元）的公司旗下。

当 8 月份首次有报道称 Nvidia 正在为[被经常描述为](https://techcrunch.com/2022/05/09/hugging-face-reaches-2-billion-valuation-to-build-the-github-of-machine-learning/)“AI 模型界 GitHub”的平台准备巨额收购要约时，人们很快便对该交易可能对平台开放性和硬件中立性产生的影响表示担忧。正如 *The New Stack* [当时报道的那样](https://thenewstack.io/nvidia-hugging-face-acquisition-neutrality/)，Hugging Face 的价值部分在于为开发者提供了一个中立的场所，以便在 Nvidia、AMD、Intel 和云加速器之间查找并部署开放模型——如果该平台仅由其中一家公司拥有，那么结果会如何引发了质疑。

## 保持 Hugging Face 开放

归根结底，这就是为什么 Nvidia 创始人、总裁兼首席执行官 [Jensen Huang](https://en.wikipedia.org/wiki/Jensen_Huang) 不遗余力地消除人们的担忧，即担心 Hugging Face 可能成为引导开发者转向 Nvidia 自身硬件和软件堆栈的工具。

> “无需使用 Nvidia 计算平台即可在 Hugging Face 上构建或部署。”

在[周四发布的官方公告中](https://blogs.nvidia.com/blog/nvidia-to-acquire-hugging-face/)，Jensen Huang 就中立性做出了一系列明确的承诺，指出 Hugging Face 将“保持作为整个 AI 生态系统的开放平台”，继续支持多种云和加速器，并强调“无需使用 Nvidia 计算平台即可在 Hugging Face 上构建或部署。”

“Hugging Face 将继续支持来自整个生态系统、来自每一位模型构建者的开源和开放权重模型，”Jensen Huang 写道。“它将继续支持多云和多加速器开发与部署，因此构建者可以使用最适合其工作的硬件和基础设施。”

事实上，很明显 Nvidia 已经注意到了围绕此次即将进行的收购所引发的担忧。在 Jensen Huang 这篇相对简短的公告中，“开放”一词出现了不少于 19 次，这凸显了这种保证对于 Nvidia 推销这笔交易的核心地位。

Jensen Huang 还[提到了最近的一封公开信](https://thenewstack.io/nvidia-open-weight-letter/)，内容关于开放权重模型。该信由他与来自整个 AI 行业的高管和研究人员（包括来自 Hugging Face 的成员）共同签署。信中指出，开放权重模型对于扩大 AI 获取途径、加强竞争以及让开发者更好地控制模型的部署和调整方式至关重要。

无论如何，Nvidia 本身也一直在大力推动开放权重 AI，包括通过其 Nemotron 模型以及[更广泛的努力](https://thenewstack.io/nvidia-local-frontier-models/)，使前沿级模型更容易在本地运行。Hugging Face 联合创始人兼首席执行官 [Clément Delangue](https://www.linkedin.com/in/clementdelangue/) 几个月前甚至称 Nvidia 为“[美国开源 AI 之王](https://www.linkedin.com/posts/clementdelangue_so-much-great-work-lately-from-nvidia-the-share-7467253070373093377-4b48/)”，指出了其在 Hugging Face 上不断增长的公共模型、数据集和 Spaces 的收藏。

在周四宣布该消息后，Clément Delangue 在一篇宣布此次交易的新帖子中重申了这一立场，认为 Hugging Face 已经达到了一个临界点，即保持开源 AI 的竞争力将需要更多的资源。

> “它需要更多的计算能力、更多的支持、更多的协作和更多的能见度。” —— Hugging Face 首席执行官 Clément Delangue

“在创办 Hugging Face 10 年后，开源 AI 正处于一个转折点，”Clément Delangue [在 LinkedIn 上写道](https://www.linkedin.com/posts/clementdelangue_super-happy-to-share-our-intention-to-join-activity-7501248639705464832--RTv?utm_source=social_share_send&utm_medium=member_desktop_web&rcm=ACoAAAKviRMBcX5r1q4mPiPDFxquTiZC0hbfIYQ)。“感谢社区，我们已经证明它可以成为闭源 API 的补充，甚至是替代方案。但要让它更大规模地实现，它需要更多的计算能力、更多的支持、更多的协作和更多的能见度。”

他补充说，Nvidia 已承诺在保持平台开放、独立和计算中立的同时支持 Hugging Face，创始人和现有团队也将留任。

“我们认为，我们可以共同使开源成为构建 AI 的默认方式，”Clément Delangue 写道，并设定了一个帮助 1 亿 AI 构建者“拥有自己的智能，而不是租赁它”的目标。

## GitHub 作为历史先例

然而，对于这种保证持谨慎态度是有一定历史先例的。当微软在 [2018 年以 75 亿美元收购 GitHub 时](https://news.microsoft.com/source/2018/06/04/microsoft-to-acquire-github-for-7-5-billion/)，它同样承诺该平台将保持独立和开放。GitHub 在很大程度上保留了这种开放性，尽管微软后来使用公共 GitHub 代码来帮助训练专有、付费的 Copilot 服务，[引发了开源社区部分人群的强烈抵制](https://techcrunch.com/2022/07/01/open-source-developers-urged-to-ditch-github-following-copilot-launch/)。

事实上，这种明显的比较可能实际上低估了 Nvidia 面临的挑战。在为《福布斯》撰写的[最新分析中](https://www.forbes.com/sites/janakirammsv/2026/08/31/nvidia-is-not-microsoft-and-hugging-face-is-not-github/)，技术分析师 Janakiram MSV 认为，Hugging Face 的中立性具有 GitHub 从未遇到过的硬件维度。Hugging Face 维持着涵盖 AWS Trainium 和 Inferentia、Google TPU、Intel Gaudi、AMD Instinct 以及其他加速器的集成。在 Nvidia 的所有权下，对竞争对手芯片的持续支持将成为考验该平台长期保持中立性的真正试金石。

## 交易尚未完成

至于收购本身，目前还没有最终敲定。在提交给美国证券交易委员会 (SEC) 的[一份文件中](https://www.sec.gov/Archives/edgar/data/1045810/000104581026000078/nvda-20260902.htm)，Nvidia 指出预计该交易将在 2027 年上半年完成，具体取决于惯例成交条件和监管部门的批准。鉴于 Nvidia 在 AI 基础设施中的崇高地位以及 Hugging Face 作为开放模型主要分发点的重要角色，这些批准不太可能仅仅是走过场。Nvidia 的文件还指出，未来围绕开源 AI 的监管可能会影响 Hugging Face 的运营或增加合规成本。

> “Hugging Face [将]继续允许模型制作者、开发者和用户上传和下载他们选择的模型和数据集，并支持其他芯片供应商。”

值得注意的是，Nvidia 还利用其 SEC 文件重申了其中立承诺，声明根据该承诺，“Hugging Face 将继续允许模型制作者、开发者和用户上传和下载他们选择的模型和数据集，并支持其他芯片供应商。”

在约 129 亿美元的头条价格中，约 119 亿美元将支付给 Hugging Face 股东，另有最高 10 亿美元预留给加入 Nvidia 的员工的股权保留奖励。

虽然头条价格通常四舍五入为 129 亿美元，但实际数字是一个奇怪的 12,930,300,000 美元。这并非巧合，正如 Hugging Face 联合创始人 Thomas Wolf [在 LinkedIn 的一篇文章中提到的那样](https://www.linkedin.com/posts/thom-wolf_so-happy-to-finally-share-this-news-in-person-activity-7501249596896157697-reL3?utm_source=social_share_send&utm_medium=member_desktop_web&rcm=ACoAAAKviRMBcX5r1q4mPiPDFxquTiZC0hbfIYQ)。对于那些还不清楚的人来说，129303 是 🤗 表情符号的十进制 Unicode 值，而 #129303 是一种向 Nvidia 品牌致敬的绿色代码。

这是一个隐藏在今年最大的 AI 交易之一中的精巧彩蛋。
