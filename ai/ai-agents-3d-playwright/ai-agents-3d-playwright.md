PhiloLabs利用AI代理仅花费33美元构建了旧金山联合广场的3D模型。该实验展示了多智能体协作、自动化视觉测试及代码审查流程，虽成功还原场景，但AI在处理原始数据缺失及复杂交互逻辑时仍面临局限。

> 译自：[It cost $33 to build a virtual Union Square. Here's what the agents got wrong.](https://thenewstack.io/ai-agents-3d-playwright/)
> 
> 作者：Amanda Caswell

PhiloLabs 想要了解一组 AI 编程代理在构建那些“仅靠能运行的代码是不够的”项目时能走多远。在最近发表的一项实验中，该公司让 [Claude Fable 5.1](https://thenewstack.io/anthropic-fable-5-1-launch/) 代理基于真实的地理数据和参考图像，对旧金山的联合广场进行了 3D 重建。

两小时后，代理们在浏览器中构建了一个可运行的 [Three.js](https://threejs.org/) 版本联合广场。该[实验](https://github.com/PhiloLabs/fable-5-1-worlds)包含了 453 个建筑轮廓、75 个定制立面和 129 个命名的店面，以及 220 名行人和 109 辆穿过场景的车辆，其中包括鲍威尔街的缆车。

但让应用程序运行只是实验的一部分。PhiloLabs 还希望代理能捕捉到[传统测试会遗漏](https://thenewstack.co/go-language-ai-agents/)的视觉问题，因此它将 Playwright 纳入了开发循环。

整个运行过程消耗了大约 800 万个 token，API 调用成本约为 33 美元。

> 整个运行过程消耗了大约 800 万个 token，API 调用成本约为 33 美元。

## Playwright 作为代理的视觉

PhiloLabs 将重建工作分配给处理地理研究、建筑几何、纹理、店面和场景其他部分的子代理。一旦它们的工作在浏览器中运行，Playwright 就会移动经过 34 个预设的摄像机位置，并捕获截图，这些截图可以与真实联合广场的照片进行比对。

总共，代理生成了 147 张对比表，这使得更容易发现那些技术上正确但看起来仍然不对劲的地方。例如，建筑可能位置正确但比例不对，或者店面可能出现在街道的错误一侧。每次使用相同的摄像机位置也更容易观察从一次迭代到下一次的变化。

> 总共，代理生成了 147 张对比表，这使得更容易发现那些技术上正确但看起来仍然不对劲的地方。

## 代理审查代理

随后，PhiloLabs 让专业代理审查这些材料，其中一些专注于建筑和地理，另一些专注于技术艺术和交互。它们共同对联合广场的构建生成了九份报告。

这些报告成为了下一次迭代的待办事项清单。开发代理可以解决审查员的发现并重新运行场景。

这种分工很有用，因为并非每个错误都能很好地转化为测试。你可以检查建筑是否放置在正确的坐标上，但要编写一个告诉你街道是否真的看起来像联合广场的测试要困难得多。

## 填补源数据的空白

代理们并不是从一个可以直接重建的成品 3D 模型开始的。它们必须汇总开放的地理数据（主要是 [OpenStreetMap](https://www.openstreetmap.org/copyright) 和 USGS 高程数据）以及有关真实地点的信息，然后将所有这些转化为可以在浏览器中运行的几何图形、立面和对象。

仍然有许多空白需要填补，因为地理数据可以告诉代理建筑物属于哪里，却无法显示其立面的样子，而照片只捕捉了从特定角度可见的建筑物部分，这使得当两个来源都没有提供答案时，代理必须自己做决定。

另一个检查工作的代理并不能保证这些决定是正确的，特别是当源材料本身就不完整时，因为审查者可能会错过第一个代理遗漏的同样问题。

## 33 美元能买到什么

800 万个 token 对于单个应用程序来说是大量的模型活动。然而，据报道，联合广场运行的 API 成本约为 33 美元。

PhiloLabs 将任务分配给子代理，并行运行任务，并利用缓存的上下文，而不是让单个代理反复从头开始处理整个项目。

尽管如此，联合广场仍然是一个相当受限的实验。一旦代理进入复杂的应用程序，截图的作用就不那么大了。[Spline 最近使用 Claude Code 代理重构了其 3D 编辑器](https://thenewstack.io/spline-v2-mcp-agents/)，但完成的界面只显示了这些代理构建内容的一部分。埋藏在代码中或由人们实际使用编辑器方式触发的问题可能永远不会出现在截图中。

> 800 万个 token 对于单个应用程序来说是大量的模型活动。然而，据报道，联合广场运行的 API 成本约为 33 美元。
