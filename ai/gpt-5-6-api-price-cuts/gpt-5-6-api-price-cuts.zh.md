**OpenAI在两款GPT-5.6模型发布仅三周后便下调了其API价格**。周四，该公司宣布 GPT-5.6 Luna 的价格下调了 80%，GPT-5.6 Terra 的价格下调了 20%，而其主要推理模型 GPT-5.6 Sol 的价格保持不变。

“今天进行了大幅降价，”OpenAI 首席执行官 Sam Altman 在周四发布的 X 帖子中写道。“我们希望在每个层面都提供最佳的价格/智能比。”

> “我们希望在每个层面都提供最佳的价格/智能比。”

Luna 目前的定价为每百万输入 token 0.20 美元，每百万输出 token 1.20 美元，此前分别为 1 美元和 6 美元。Terra 的定价为每百万输入 token 2 美元，每百万输出 token 12 美元，此前分别为 2.50 美元和 15 美元。Sol 的价格保持在每百万输入 token 5 美元，每百万输出 token 30 美元。

使用 Luna 的开发者无需更改流程，但推理成本将降低。大容量任务现在运行成本将大大降低，且无需任何代码更新或模型变更。

**此举时机不同寻常，因为 AI 供应商**通常在发布新模型系列后的几个月内都会保持价格稳定。OpenAI 在 [7月9日 GPT-5.6 可用](https://thenewstack.io/openai-gpt-56-live/) 不到一个月后就下调了价格。

> ……对于模型而言，服务成本可能比基准性能的微小差异更重要。

## 基础设施收益推动节省成本

该公司表示，这些降价之所以可能，是因为 GPT-5.6 背后的基础设施得到了改善，这使该公司能够提供“每美元更多的智能”。

然而，这些基础设施升级是在预料之中的。在价格公布的前一天，OpenAI 分享了一份 [工程概览](https://thenewstack.io/gpt-5-6-serving-efficiency/)，解释了 Codex 和 ChatGPT Work 在推理堆栈中的优化。

## 重写 GPU 内核以提高效率

OpenAI 工程师重写了生产 GPU 内核，将服务成本降低了约 20%。他们还重新设计了 Sol 的推测解码系统，使 token 生成效率提高了 15% 以上。该公司还更新了其智能体运行时，通过在多步工作流中更多地使用提示词缓存，减少了重复的提示词计算。

## 智能体放大了推理成本

最近，开发者越来越关注推理成本，因为智能体为了完成一项任务，通常会进行数十甚至数百次模型调用。对于这些工作负载，[服务成本可能比模型之间的基准性能的微小差异更重要](https://thenewstack.io/agentic-ai-token-costs/)。

不可忽视的问题是，来自海外的竞争日益加剧。来自 Moonshot 等中国 AI 公司的低成本开放权重模型正在迫使商业供应商展示出不仅是更好的性能，还有 [更好的生产环境定价](https://thenewstack.io/kimi-k3-open-weight-coding/)。OpenAI 和 Anthropic 知道，单纯依靠性能已经不再是唯一选择，这促使他们匹配中国产品的价格。

问题在于，这些步骤中大多数并不需要像 Sol 这样的模型，而中国实验室已经弄清楚了如何将更强大的能力集成到高效模型中；对于每天运行数十亿 token 的公司来说，这是一个有用的选择。

能够将简单任务发送给开源模型，并将昂贵的 API 留给困难任务，这会产生很大影响；OpenAI 正押注于其对 Luna 的 80% 降价来缩小这一差距。突然间，切换到自托管模型似乎不再那么麻烦了。

## 竞争重塑模型定价

这些定价变化正值 OpenAI 和 Anthropic 不断调整其最新模型系列的经济性之际——本月早些时候，[三家公司在短短一周内就上演了这一动态](https://thenewstack.io/openai-spacexai-meta-price-war/)。本周早些时候，OpenAI 在发现长时间的编程会话比预期更快耗尽配额后，[提高了 ChatGPT Work 和 Codex 的 GPT-5.6 使用限制](https://thenewstack.io/sol-usage-limits-reset/)。随着企业客户将更大的智能体工作负载投入生产，Anthropic 也 [进行了定价调整并增加了高级推理层](https://thenewstack.io/opus-5-agentic-coding-cost/)。

此公告突显了行业在基础设施方面的一个趋势。现在，每一个百分点的服务效率提升都可以直接转化为更低的 API 价格，将成本优化变成一种竞争优势，而不仅仅是一个工程目标。
