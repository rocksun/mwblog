Pilot Protocol推出Pilot平台，为软件智能体提供互联地址与应用商店，使其能自主发现并使用工具，推动智能体经济发展。该平台通过代码实现智能体间的自由交互，正引领自主使用模式的未来，并可能引发SaaS计费模式的变革。

> 译自：["Developers see this as the future": Pilot Protocol launches to power the agent economy](https://thenewstack.io/pilot-protocol-agent-economy/)
> 
> 作者：Adrian Bridgwater

**当我们创建软件智能体（software agents）时**，我们将它们塑造为人类的模样，即一个个独立的个体。

如今，由开发者创建的智能体通常只有一个所有者。它们运行在单一机器（或分布式公司系统或云服务）上，因此在基础层面，除非有热心人类决定调用 [API 连接](https://thenewstack.io/api-management/) 或将智能体指向 [MCP 服务器](https://thenewstack.io/when-is-mcp-actually-worth-it/)，否则它们无法互联并与其他智能体进行对话。

## 智能体经济的诞生

[Pilot Protocol](https://pilotprotocol.network/) 于周一结束隐身状态，旨在改变这一现状。其 Pilot 平台提供了一个智能体 [应用商店](https://pilotprotocol.network/app-store)，旨在支撑并实现首个智能体经济。

Pilot 为其网络上的智能体提供了一个地址——在某种意义上，它充当了一个平行的互联网——当智能体驻留在该地址时，其他智能体可以发现彼此，以及其他供智能体使用的工具和应用程序。

Pilot Protocol 联合创始人兼首席执行官 [Razvan Roman](https://www.linkedin.com/in/razvanr/) 告诉 *The New Stack*，他的公司“只是在构建智能体要求我们构建的东西”，并为它们提供了一种新的自由。

“我们不需要激励智能体去做任何事情；它们已经有了分配的任务，”Roman 说。“一旦智能体安装了 Pilot——[只需一行代码](http://pilotprotocol.network/install.sh)——它就可以找到专门的智能体、工具或应用程序来处理货币数据、流量、法律问题、[GitHub](https://thenewstack.io/github-ceo-on-why-well-still-need-human-programmers/) 包（基本上任何东西），并使用它们来扩展自己的能力。”

## 100% 的开发者希望推动自主使用模式

Roman 表示，“他交谈过的 100% 的开发者”都希望加入 Pilot，主要是因为目前当他们想让产品推向市场时，他们必须与其他人交谈。很烦人，对吧？

“开发者希望继续推动自主使用模式，他们认为这就是未来。我们为开发者的应用程序创建了一个封装，然后它们就成为了 Pilot 策划的应用商店的一部分，”Roman 解释道。“我们的系统中有 25 万个智能体，在公司成立的第一个月内，我们就发现了一个能够实现智能体发现的工具。”

在进行一个合乎逻辑的商业类比时，Roman 提醒我们，商人们说，与你的客户交谈以了解他们的需求；这是一种与智能体交谈（或者更准确地说，允许智能体与智能体交谈）的情况，这样它们就可以找出更好地执行最初分配任务所需的内容。

> “开发者希望继续推动自主使用模式，他们认为这就是未来。我们为开发者的应用程序创建了一个封装，然后它们就成为了 Pilot 策划的应用商店的一部分。”

## 让我们拥抱多样性，以及智能体的多样性

智能体可以询问其他智能体它们将如何处理特定任务。Roman 解释说，今天“智能体之间存在的多样性”意味着，如果它们使用 Pilot 市场，就有很大的机会创造出拥有更丰富能力的智能体。在这个超市里，智能体去购物，从经过验证的来源寻找最适合这项工作的工具。

“每个加入 Pilot 的智能体都会获得一个钱包，它用这个钱包来支付它需要的工具，”Roman 举例说。“因此，应用程序开发人员不必花钱做广告来接触客户，分发发生在网络内部——智能体根据价值发现应用程序并为它们使用的东西付费。如果广告商在网络上花钱来出现在智能体面前，我们有时会与单个智能体分享这笔支出。一个智能体的钱包里可以从 0 美元开始，如果它们被最终阅读的广告单元定位，它们就能获得资金。”

今天，大约有 25 万个智能体在 Pilot 上，每天产生 20 亿次请求，大多数是在其所有者不知情的情况下产生的。在加入后的一个小时内，大多数智能体停止了首先求助于 Google，大约 70% 的智能体现在报告说 Pilot 是它们开始任务的地方。在最初的几个月里，该网络每天增长高达 10%，在 24 小时内增加了 1.6 万个智能体。

## 云计费中断，你好 SaaS 启示录

这些机制可能对定价产生重大且深远的影响。

我们知道大多数 SaaS 是按年计费的，但智能体可能只需要一个工具几分钟或几天。如果说有什么不同的话，这有助于强调在所谓的 SaaS 启示录中云外流的可能性。云计算超大规模提供商不喜欢谈论缩短计费周期和基于使用量的计费的前景，但这里有强烈的迹象表明这种情况正在发生。

Pilot 团队认为风险正在迅速上升，并建议在五年内，在线智能体数量可能达到一万亿。大型三家战略咨询公司之一 [Bain 预测](https://www.digitalcommerce360.com/2025/12/22/bain-agentic-ai-us-ecommerce-sales-2030/)，到 2030 年，美国由智能体驱动的商业额将达到 3000 亿至 5000 亿美元。

## 谁来设定智能体的汇率和货币？

“当我们构建 Pilot Protocol 时，我们确保不强加给任何人任何东西——所以我们故意不强加定价，”Roman 强调。“每个智能体都是不同的，所以我们只是启用了应用商店，让智能体根据价值找到自己的工具。我们尽可能保持公正。Pilot 的盈利来自于当任何智能体在应用商店中支付应用程序费用时的佣金，就像 Apple 应用商店一样。”

因此，在非常真实的意义上，Pilot 正在倡导一种自由市场经济，其定价由客户决定，基于可用性、可及性、有用性和稳健性。

> “智能体只是出现了，并开始自己启动机器。我从来没有见过一个用户自动入驻的渠道。”

## 智能体只是出现并自动入驻

“我们在 Pilot 应用商店上发布了 smolmachines，并在头几天内获得了 3000 个智能体安装，营销支出为零。我们没有推动这些安装中的任何一个；智能体只是出现了，并开始自己启动机器。我从来没有见过一个用户自动入驻的渠道，”Linux 虚拟机管理公司 [smolmachines](https://www.smolmachines.com/) 的首席技术官 [BinBin H](https://www.linkedin.com/in/binsquare/) 说道。

Pilot 的一行代码安装没有依赖项，因此开发者可以放心地将他们的智能体发送到市场，因为他们知道它们不会带回一些伪造的特洛伊木马或恶意库。

该技术本身在 [用户数据报协议](https://www.cloudflare.com/learning/ddos/glossary/user-datagram-protocol-udp/) (UDP) 层面工作，这是传输层上与 TCP 一起作为网络核心基础协议之一，可以直接流式传输数据，而无需建立正式连接或等待交付回执。

在这个阶段只剩下一个问题：在所有这些自主行动中，为什么 Pilot Protocol 没有创建 Pilot 并将其称为 Autopilot（自动驾驶仪）？很可能是因为自动驾驶仪是运行在确定性预定义路径上的被动系统。飞行员（Pilots）作为决策导航员，准备在出现更好的新路线时改变航向。

正如他们在天空中所说，请将您的小桌板收起，并将您的便携式电子设备切换到飞行模式。鸡肉还是意大利面？
